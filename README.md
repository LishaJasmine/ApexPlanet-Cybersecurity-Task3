# ApexPlanet-Cybersecurity-Task

## Web Application Security Testing

This repository contains the practical work completed as part of Task 3 of the ApexPlanet Cybersecurity Internship.

### Objective
To understand and demonstrate common web application vulnerabilities using DVWA (Damn Vulnerable Web Application), along with security testing tools and techniques.

### Tools and Technologies
- Kali Linux
- DVWA (Damn Vulnerable Web Application)
- Burp Suite Community Edition
- Firefox Browser
- PHP and Apache
- Linux Terminal

### Practical Exercises

| No. | Practical | Description |
|---|---|---|
| 1 | SQL Injection | Understanding database query manipulation |
| 2 | Reflected XSS | Demonstrating reflected cross-site scripting |
| 3 | Stored XSS | Demonstrating persistent cross-site scripting |
| 4 | CSRF | Exploring cross-site request forgery |
| 5 | File Inclusion | Exploring local and remote file inclusion |
| 6 | Burp Suite | Intercepting and inspecting HTTP requests |
| 7 | HTTP Security Headers | Examining HTTP response security headers |
